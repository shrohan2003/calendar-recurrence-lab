# Calendar Recurrence Lab

[Open the interactive demo](https://shrohan2003.github.io/calendar-recurrence-lab/)

Cancel individual meetings in a six-occurrence hourly calendar and compare the expected schedule with recorded output from two revisions of Python’s icalevents. All 64 cancellation patterns have their own downloadable synthetic ICS file. The browser displays measurements generated by Python.

The default example cancels 10:00, 11:00 and 13:00 UTC. The base revision returns an empty calendar. The proposed change keeps 09:00, 12:00 and 14:00.

## Reproduce

With Python 3.12, Git and network access, run these commands from the repository root.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python reproduce.py --check
```

The check fetches the pinned revisions into a temporary directory, runs each fixture through both parsers, checks the proposed result against the expected hours, and compares the results with the published table. To serve the demo locally, run `python3 -m http.server 8000` and open http://localhost:8000.
